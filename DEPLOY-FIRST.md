# Do this first

This rebuild is intended to be easy to deploy.

1. Create a fresh GitHub repo called `trafficcampaign`.
2. Upload the contents of this folder.
3. Import that repo into Vercel.
4. Deploy with the defaults.

There are **no environment variables** and **no external services** to configure.

After it is live, test these URLs:

- https://trafficcampaign.com/
- https://trafficcampaign.com/articles
- https://trafficcampaign.com/tools
- https://trafficcampaign.com/sitemap.xml
- https://trafficcampaign.com/robots.txt
- https://trafficcampaign.com/llms.txt
- https://trafficcampaign.com/llms-full.txt
- https://trafficcampaign.com/rss.xml
